# React Native Interview Handbook — Say This

Open `index.html` in any browser. No install, no server, no network needed.

Same 180 questions as the original handbook, plus 39 new ones on design principles, patterns and mobile system design. Each entry has:

- **Say this in the interview** — the answer written the way you would actually speak it, in plain English. Roughly 30 seconds out loud.
- **Quick example** — one short snippet you could write on a whiteboard to back it up.

Search, category filter, bookmarks, "mark as prepared" progress and the theme are stored in this browser only. Progress here is kept separately from the original handbook, so the two do not overwrite each other.
